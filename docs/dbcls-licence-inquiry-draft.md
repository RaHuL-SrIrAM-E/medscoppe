**The licence statements I found, which differ**

1. The README currently in the `LATEST` directory (`README_e.html`; update history entry

   Attribution-Share Alike 2.1 Japan", and requires derivative works to be distributed under the same licence.
3. The release 4.0 data files themselves are dated 2013, before the 2025 change.

**How I intend to use the data**

- A clinician-support and educational prototype for immersive (WebXR) anatomy exploration, entered in
  the Meta VR Start Developer Competition 2026. It uses synthetic scenarios only and is not a medical
  device or a diagnostic tool.
- Non-commercial at this stage. [State whether you intend any later commercial use.]

**What I would redistribute (adapted material)**

- Meshes merged per FMA concept, split using the dataset's part-of and is-a element lists (for example
  separating lung-lobe airways, pulmonary arteries and pulmonary veins), converted to metres and
  Y-up, welded, decimated from about 1.1 million to about 132,000 triangles, with smooth normals, and the
  skin cropped to the torso, packaged as a single glTF binary (GLB), plus a JSON registry carrying FMA
  concept ids and my own structure ids.
- Lung lobe surfaces **generated by me** from the airway and vessel geometry (release 4.0 has no continuous lung
  parenchyma meshes); these are labelled in the application as illustrative approximations.
- The raw OBJ files are not redistributed.
